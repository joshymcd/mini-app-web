# Mini Apps

A static marketing site with screenshots and short demos captured from Mini Apps. The app data in the media is synthetic.

## Publishing

GitHub Pages serves the root of `main`. The site uses plain HTML, CSS, and JavaScript, so there is no build step. Use relative paths for new assets to keep links working under `/mini-app-web/`.

## Local preview

Open `index.html` in a browser, or run `python3 -m http.server` from the repository root.
